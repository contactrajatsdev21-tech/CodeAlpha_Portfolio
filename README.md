# 🚀 CodeAlpha_Portfolio

Welcome to my personal portfolio website! This project was developed as Task 3 for the **Frontend Development Internship** at **CodeAlpha**.

## 📝 Project Overview
This is a fully responsive, modern personal portfolio website designed to showcase my skills, educational background, and development projects. It features a clean UI, smooth scrolling, and dynamic navigation.

## ✨ Features
*   **Responsive Layout:** Adapts perfectly to mobile, tablet, and desktop screens.
*   **Modern UI/UX:** Clean design with hover animations and a sticky navigation bar.
*   **Sections Included:** Home (Hero), About Me, Core Skills, Featured Projects, and Contact Information.

## 🛠️ Technologies Used
*   **HTML5:** For page structure and semantic elements.
*   **CSS3:** For styling, Flexbox/Grid layouts, and smooth transitions.
*   **JavaScript:** For dynamic DOM manipulation and scroll effects.
